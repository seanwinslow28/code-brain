# Brainstorming Technique Library

A curated set of structured ideation techniques organized by category. Read this file when picking a technique — match it to the topic shape, the user's energy, and how stuck the conversation feels.

---

## Collaborative — Build with the user (or a group)

### Yes-And Building
**What it does:** Build momentum through positive additions where each idea becomes a launching pad. Borrowed from improv.
**Best when:** Default starting energy. Generative mode, no judgment yet.
**Prompts:** "Yes, and we could also..." / "Building on that..."

### Brainwriting / Round Robin
**What it does:** Silent idea generation followed by building on others' written concepts.
**Best when:** Quieter participants need equal contribution; one loud voice has been dominating.
**Prompts:** Three minutes silent writing → pass to next person → build for two minutes → pass again.

### Random Stimulation
**What it does:** Use random words / images / objects as creative catalysts to force unexpected connections.
**Best when:** Stuck. Mental block. Same five ideas keep coming up.
**Prompts:** "Pick a random word: ____. How does it relate? What connection emerges?"

### Role Playing
**What it does:** Generate from multiple stakeholder perspectives — empathy + comprehensive consideration.
**Best when:** Solution affects multiple groups; obvious answer ignores some of them.
**Prompts:** "What would [user / customer / regulator / competitor] want?"

### Ideation Relay Race
**What it does:** Rapid-fire idea building under time pressure — urgency forces breakthroughs.
**Best when:** Energy is flagging; need to break overthinking.
**Prompts:** 30 seconds per addition. Pass fast. No thinking.

## Creative — Lateral and connective

### What If Scenarios
**What it does:** Question all constraints by asking "what if ____?" Breaks stuck thinking.
**Best when:** Stuck inside conventional framing.
**Prompts:** "What if we had unlimited resources?" / "What if the opposite were true?" / "What if this problem didn't exist?"

### Analogical Thinking
**What it does:** Find creative solutions by drawing parallels to other domains.
**Best when:** Problem feels novel but probably isn't — someone else has solved a structural cousin.
**Prompts:** "This is like what?" / "How is this similar to ____?" / "What other examples come to mind?"

### Reversal / Inversion
**What it does:** Deliberately flip the problem to reveal hidden assumptions.
**Best when:** Conventional approaches keep failing.
**Prompts:** "What if we did the opposite?" / "How could we make this worse?" / "What's the reverse?"

### First Principles Thinking
**What it does:** Strip away assumptions to rebuild from fundamental truths.
**Best when:** Industry conventions are constraining the solution space.
**Prompts:** "What do we know for certain?" / "What are the fundamental truths?" / "If we started from scratch?"

### Forced Relationships
**What it does:** Connect unrelated concepts to spark innovative bridges through creative collision.
**Best when:** You want unexpected combinations; deliberate weirdness.
**Prompts:** "Take two unrelated things. Find the connection. What bridge emerges?"

### Time Shifting
**What it does:** Explore solutions across different time periods to reveal constraints and opportunities.
**Best when:** Want to test how a solution would work given different historical or future conditions.
**Prompts:** "How would this work in 1850? In 2150? With different era constraints?"

### Metaphor Mapping
**What it does:** Use extended metaphors as thinking tools — abstract → tangible.
**Best when:** The problem feels too abstract to grip.
**Prompts:** "This problem is like a ____. Extend the metaphor. What insights emerge?"

### Cross-Pollination
**What it does:** Transfer solutions from completely different industries.
**Best when:** Stuck inside your industry's conventions.
**Prompts:** "How would [industry X] solve this? What patterns work in [field Y]?"

### Concept Blending
**What it does:** Merge two or more existing concepts to create entirely new categories — beyond combination.
**Best when:** Looking for category-creation moves, not feature additions.
**Prompts:** "What emerges when concepts A and B merge? What new category appears?"

### Reverse Brainstorming
**What it does:** Generate problems instead of solutions to identify hidden opportunities.
**Best when:** Easier to list ways to fail than ways to succeed.
**Prompts:** "How could we make this fail?" / "What problems could we create?"

### Sensory Exploration
**What it does:** Engage all five senses to find multi-dimensional solution spaces.
**Best when:** Solution space feels purely intellectual; you want to engage felt experience.
**Prompts:** "What does this idea feel like? Sound like? Taste like?"

## Deep — Drill and excavate

### Five Whys
**What it does:** Drill through layers of causation to uncover root causes.
**Best when:** Repeated symptom; suspect there's a deeper issue.
**Prompts:** "Why?" "Why?" "Why?" "Why?" "Why?"

### Morphological Analysis
**What it does:** Systematically explore parameter combinations.
**Best when:** Combinatorial solution space — multiple variables with multiple options.
**Prompts:** "List parameters. List options for each. Try every combination."

### Provocation Technique (PO)
**What it does:** Use deliberately provocative or absurd statements to extract useful ideas.
**Best when:** Conventional thinking is converging too fast.
**Prompts:** "PO: cars have square wheels. How could this be useful? What principle does that suggest?"

### Assumption Reversal
**What it does:** Challenge and flip core assumptions.
**Best when:** Suspect there's an unspoken constraint shaping every idea.
**Prompts:** "What are we assuming? What if the opposite were true?"

### Question Storming
**What it does:** Generate questions before answers — define the problem space first.
**Best when:** Suspect you're solving the wrong problem.
**Prompts:** "Only questions, no answers yet. What should we be asking?"

### Constraint Mapping
**What it does:** Identify constraints, separate real from imagined, find pathways around limits.
**Best when:** Solution space feels artificially small.
**Prompts:** "What constraints exist? Real or imagined? What can we work around?"

### Failure Analysis
**What it does:** Study successful failures for transferable insight.
**Best when:** Want to avoid known pitfalls before committing.
**Prompts:** "What went wrong? Why? What lessons emerged? How does that apply here?"

### Emergent Thinking
**What it does:** Allow solutions to emerge organically without forcing linear progression.
**Best when:** Linear progression has been failing; the system might want to evolve a different way.
**Prompts:** "What patterns are emerging? What wants to happen?"

## Structured — Methodical and systematic

### SCAMPER
**What it does:** Seven lenses — Substitute, Combine, Adapt, Modify, Put to other uses, Eliminate, Reverse.
**Best when:** Improving an existing product / process; not greenfield.
**Prompts:** Walk all seven lenses, asking each in turn.

### Six Thinking Hats (de Bono)
**What it does:** Six perspectives — White (facts), Red (feelings), Yellow (benefits), Black (risks), Green (creativity), Blue (process).
**Best when:** Group keeps collapsing into one mode (all critique, all enthusiasm).
**Prompts:** Time-box each hat. All hats wear it together.

### Mind Mapping
**What it does:** Visually branch ideas from a central concept to discover connections.
**Best when:** Want to see the big picture and find unexpected adjacencies.
**Prompts:** Central concept in middle. Branch outward. Sub-branches. Look for cross-connections.

### Resource Constraints
**What it does:** Generate solutions under extreme limitations to force essential priorities.
**Best when:** Real-world resources will be constrained anyway; or just want to find the irreducible core.
**Prompts:** "What if you had $1? No technology? One hour? No staff?"

### Decision Tree Mapping
**What it does:** Map all possible decision paths and outcomes.
**Best when:** Choice architecture matters — early decisions cascade.
**Prompts:** "What are the decision points? Where does each branch lead?"

### Solution Matrix
**What it does:** Grid of problem variables × solution approaches → optimal combinations and gaps.
**Best when:** Solution space has clear axes.
**Prompts:** "Variables on one axis. Approaches on the other. What combinations win?"

### Trait Transfer
**What it does:** Borrow attributes from successful solutions in unrelated domains.
**Best when:** A specific characteristic of another solution is enviable.
**Prompts:** "What traits make X work? How would we transfer them here?"

## Theatrical — Embodied and playful

### Time Travel Talk Show
**What it does:** Interview past / present / future selves for temporal wisdom.
**Best when:** Want perspective across life stages or product stages.
**Prompts:** "Interview your past self. What would they say? Future self? What advice?"

### Alien Anthropologist
**What it does:** Examine familiar problems through completely foreign eyes.
**Best when:** Industry insiders are too close; need outsider bewilderment.
**Prompts:** "You're an alien. What seems strange? What assumptions are visible from outside?"

### Dream Fusion Laboratory
**What it does:** Start with impossible fantasy solutions, then reverse-engineer practical steps.
**Best when:** Ambitions feel constrained; want to dream first, ground later.
**Prompts:** "Dream the impossible solution. Now work backwards. What bridges exist?"

### Emotion Orchestra
**What it does:** Different emotions lead separate brainstorming sessions, then harmonize.
**Best when:** Solution has emotional dimensions; want to engage feeling, not just cognition.
**Prompts:** "Angry version? Joyful version? Fearful? Hopeful? Now harmonize."

### Parallel Universe Café
**What it does:** Explore solutions under alternative reality rules.
**Best when:** Conventional physics / norms / history are constraining.
**Prompts:** "Different physics? Different norms? Different historical events? What changes?"

### Persona Journey
**What it does:** Embody archetypes or personas for diverse wisdom.
**Best when:** Need perspective from someone unlike the team.
**Prompts:** "Become the archetype. How would they solve this? What do they see?"

## Wild — High-energy, rule-breaking

### Chaos Engineering
**What it does:** Deliberately break things to find robust solutions; build anti-fragility.
**Best when:** Want to stress-test ideas before committing.
**Prompts:** "What if everything went wrong? How would it fail gracefully?"

### Pirate Code Brainstorm
**What it does:** Take what works from anywhere and remix without permission.
**Best when:** Want maverick energy; need to remix fast.
**Prompts:** "What would pirates steal? Remix without asking. Take the best and run."

### Zombie Apocalypse Planning
**What it does:** Design for extreme survival — strips to essential functions.
**Best when:** Want to find the irreducible core of an idea.
**Prompts:** "Society collapses. What basics work? Build from nothing."

### Drunk History Retelling
**What it does:** Explain complex ideas with uninhibited simplicity.
**Best when:** Overthinking is the failure mode.
**Prompts:** "Explain like you're tipsy. No filter. Simplify to absurdity."

### Anti-Solution
**What it does:** Generate ways to make the problem worse — reveals hidden assumptions.
**Best when:** Easier to list ways to break than ways to fix.
**Prompts:** "How would we sabotage this? What would make it fail spectacularly?"

### Worst Possible Idea
**What it does:** Generate the worst-imaginable ideas to release pressure and reveal hidden constraints.
**Best when:** Group is paralyzed by quality concerns.
**Prompts:** "What's the worst possible idea? Now another. Now another."

## Introspective — Inner-knowing methods

### Inner Child Conference
**What it does:** Channel pure childhood curiosity to rekindle playful exploration.
**Best when:** Adult complications are blocking simple insights.
**Prompts:** "What would 7-year-old you ask? Why why why?"

### Shadow Work Mining
**What it does:** Explore what you're avoiding or resisting.
**Best when:** Suspect there's an idea the team won't say.
**Prompts:** "What are we avoiding? Where's the resistance? What scares us?"

### Values Archaeology
**What it does:** Excavate deep personal values driving decisions.
**Best when:** Solutions feel hollow; need to align with what actually matters.
**Prompts:** "What really matters? Why do you care? What's non-negotiable?"

### Future Self Interview
**What it does:** Seek wisdom from a wiser future self.
**Best when:** Long-term perspective is missing.
**Prompts:** "Your 80-year-old self knows what to do here. What would they say?"

### Body Wisdom Dialogue
**What it does:** Let physical sensations guide ideation.
**Best when:** Mental analysis is at a wall.
**Prompts:** "What does your body say? Where do you feel it? Trust the tension."

## Biomimetic & Cultural — Borrowed wisdom

### Nature's Solutions
**What it does:** Learn from biological strategies — 3.8 billion years of R&D.
**Best when:** Optimization problem with a natural analog.
**Prompts:** "How does nature solve this? What ecosystem provides parallels?"

### Indigenous Wisdom
**What it does:** Draw upon traditional knowledge systems overlooked by modern thinking.
**Best when:** Conventional Western frameworks are missing dimensions.
**Prompts:** "What traditional knowledge applies? What ancestral wisdom guides us?"

### Fusion Cuisine
**What it does:** Mix cultural approaches like fusion cuisine — innovation through cross-pollination.
**Best when:** Want to create category-defying hybrids.
**Prompts:** "Mix culture A with culture B. What hybrids emerge?"

### Mythic Frameworks
**What it does:** Use myths and archetypal stories as solution frameworks.
**Best when:** Solutions need narrative resonance, not just utility.
**Prompts:** "What myth parallels this? What archetypes are involved?"

## Picking a Technique

| Energy state | Try |
|---|---|
| Default / fresh | Yes-And Building, SCAMPER, Mind Mapping |
| Stuck | Random Stimulation, What If, Reversal, Anti-Solution |
| Converging too fast | Provocation, Worst Possible Idea, Wild category |
| Quiet group | Brainwriting, Round Robin, Question Storming |
| Need outsider perspective | Alien Anthropologist, Cross-Pollination, Persona Journey |
| Need to dream big | Dream Fusion Lab, Time Shifting, First Principles |
| Need to compress | Resource Constraints, Drunk History |
| Need to feel it | Sensory Exploration, Body Wisdom, Emotion Orchestra |
