## What this is

Critiques from two external reasoners (gpt-5.5 via Codex CLI, Gemini 3 via Anti-Gravity CLI) of [[cross-domain-roadmap-synthesis]]. The synthesizer describes what the concept is; this expansion proposes what's missing.

## From Codex (gpt-5.5)

1. **Add “Wardley Map Roadmap Mode”**
   - **Anchor:** Simon Wardley, *Wardley Maps* / “Finding a Path” essays.
   - **What to add:** Replace “mutually reinforcing domains” with a value-chain map: user need → portfolio signal → agent capability → infrastructure dependency → commodity/custom boundary. Sentence pattern: “This belongs on the roadmap because it is currently custom, strategically differentiating, and upstream of X.”
   - **Unlocks:** A portfolio one-pager or Substack essay that explains *why these projects are sequenced this way*. Right now the concept says the roadmap harmonizes things; Wardley mode would let Sean argue what should be built, bought, deferred, or commoditized.

2. **Add “Portfolio as Epistemic Artifact”**
   - **Anchor:** Donald Schön, *The Reflective Practitioner*.
   - **What to add:** Treat Code-Brain, 16BitFit, and intent-engineering not as projects, but as reflective surfaces that reveal Sean’s judgment under uncertainty. Sentence pattern: “This artifact is not proof that I know X; it is proof that I notice Y, revise Z, and preserve decision trace Q.”
   - **Unlocks:** A stronger interview narrative and artifact taxonomy: demo, decision record, postmortem, critique loop, hiring signal. The current concept risks sounding like “I have many connected systems.” Schön mode turns it into “I build systems that make my thinking inspectable.”

3. **Add “Strategy Kernel Check”**
   - **Anchor:** Richard Rumelt, *Good Strategy Bad Strategy*.
   - **What to add:** Force every cross-domain synthesis to name the kernel: diagnosis, guiding policy, coherent actions. For this article: diagnosis might be “agentic-PM credibility requires executable proof, not résumé claims”; guiding policy might be “ship artifacts that demonstrate judgment plus automation”; coherent actions are the specific portfolio pieces.
   - **Unlocks:** A roadmap-review runbook or agent spec for the Vault Critic: reject synthesis notes that only state cohesion. This would directly address Sean’s complaint. The agent should ask, “Where is the diagnosis? What tension is being resolved? Which action follows that would not otherwise follow?”
