## What this is

Critiques from two external reasoners (gpt-5.5 via Codex CLI, Gemini 3 via Anti-Gravity CLI) of [[creative-automation-pipeline]]. The synthesizer describes what the concept is; this expansion proposes what's missing.

## From Codex (gpt-5.5)

1. **Add “forces-before-tools” pattern language.**  
   Anchor it on Christopher Alexander’s [*Notes on the Synthesis of Form*](https://en.wikipedia.org/wiki/Notes_on_the_Synthesis_of_Form) and *A Pattern Language*, especially the idea that good design resolves named conflicting forces, not just assembles capabilities.  
   Pattern to add: `Force A / Force B / failure if over-optimized / resolving move / reusable pipeline primitive.`  
   This unlocks a **creative automation pattern catalog** Sean can ship: “Prompt-to-asset pipelines fail when they optimize throughput over taste memory.” Current concept says “use OpenRouter models”; Alexander mode would produce agent specs like `style_continuity_guard`, `palette_pressure`, `reference_drift_detector`, and `taste_regression_gate`.

2. **Add “productive obstruction” as a first-class generation mode.**  
   Anchor it on Brian Eno and Peter Schmidt’s [*Oblique Strategies*](https://en.wikipedia.org/wiki/Oblique_Strategies), not as inspiration cards but as a pipeline primitive: deliberate constraints injected between generation passes.  
   Pattern to add: `Before rerolling, draw/choose one obstruction: remove the obvious subject, change the production material, preserve the error, invert the palette, slow the motion, make the background tell the story.`  
   This unlocks a **Substack/process essay and executable demo**: “The Anti-Prompt: why creative agents need constraints that make the first answer worse.” Right now the concept risks becoming generic “automated asset generation.” Eno mode gives Sean a distinct creative-automation thesis: agents should not only execute taste; they should disturb taste on schedule.

3. **Add “Braintrust/dailies” critique gates before automation is allowed to scale.**  
   Anchor it on Ed Catmull and Amy Wallace’s [*Creativity, Inc.*](https://en.wikipedia.org/wiki/Creativity%2C_Inc.) and Pixar’s Braintrust/dailies practice: candid review of unfinished work, with notes separated from authority.  
   Pattern to add: `Generation pass → anonymous defects list → taste-owner decision → only then upscale/batch/export.`  
   This unlocks a **creative QA runbook** for 16BitFit, portfolio visuals, and Substack headers: “No batch generation without a dailies loop.” The current concept jumps from model access to automation foundation. Catmull mode adds the missing governance layer: which artifacts deserve more compute, which defects are taste failures versus technical failures, and when the agent must stop producing and ask for direction.
