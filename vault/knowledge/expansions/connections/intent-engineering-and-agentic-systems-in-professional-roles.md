## What this is

Critiques from two external reasoners (gpt-5.5 via Codex CLI, Gemini 3 via Anti-Gravity CLI) of [[intent-engineering-and-agentic-systems-in-professional-roles]]. The synthesizer describes what the concept is; this expansion proposes what's missing.

## From Codex (gpt-5.5)

1. **Add “situated intent” as a direct contradiction to living-spec optimism.**  
   Anchor it on Lucy Suchman’s [*Plans and Situated Actions*](https://www.cambridge.org/core/books/plans-and-situated-actions/). The missing sentence pattern is: **“Intent specs are not instructions agents execute; they are resources agents use while coping with situated work.”** This would unlock a sharper Substack essay: *The Problem With Teaching Agents What To Want*. Current concept sounds like role-market alignment; Suchman lets Sean argue that professional agent systems fail when they mistake plans for work.

2. **Add STPA/STAMP as the safety grammar for agent intent.**  
   Anchor it on Nancy Leveson’s [*Engineering a Safer World*](https://mitpress.mit.edu/9780262533690/engineering-a-safer-world/) and the software-focused STPA paper by Abdulkhaleq, Wagner, and Leveson, [“A Comprehensive Safety Engineering Approach for Software-Intensive Systems Based on STPA”](https://arxiv.org/abs/1612.03109). The missing pattern: **hazard → unsafe control action → process-model flaw → constraint.** This unlocks an executable artifact Sean does not yet have: an **Agent Fleet STPA worksheet** for daily-driver, critic, synthesizer, and job-feed failure modes. It upgrades “intent engineering” from vocabulary into governance machinery.

3. **Add “mission command / Auftragstaktik” as the management lineage of agent intent.**  
   Anchor it on Stephen Bungay’s [*The Art of Action*](https://www.nicholasbrealey.com/titles/stephen-bungay/the-art-of-action/9781857885590/). The missing pattern is: **“Define intent, constraints, and freedoms; require briefback; let execution adapt locally.”** This unlocks a portfolio one-pager or agent-spec template: **Commander’s Intent for Agent Fleets**. It would make Sean’s PM-to-IC story less “I built many agents” and more “I know how to delegate under uncertainty without losing control.”
