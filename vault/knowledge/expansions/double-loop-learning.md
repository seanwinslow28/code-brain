## What this is

Critiques from two external reasoners (gpt-5.5 via Codex CLI, Gemini 3 via Anti-Gravity CLI) of [[double-loop-learning]]. The synthesizer describes what the concept is; this expansion proposes what's missing.

## From Codex (gpt-5.5)

1. **Add “Model I / Model II diagnosis,” anchored on Chris Argyris, “Teaching Smart People How to Learn”**
   - **What to add:** Double-loop learning is too generic unless it names the defensive routines that prevent learning. Add Argyris’s distinction between **Model I behavior** and **Model II behavior**: agents can “optimize insight” while still protecting their existing theory of quality.
   - **Exemplar:** Chris Argyris, **“Teaching Smart People How to Learn”** (*Harvard Business Review*, 1991); also Argyris & Schön, **Organizational Learning: A Theory of Action Perspective**.
   - **Unlocks:** A **Vault Critic failure-mode taxonomy**. Sean could ship an agent spec or Substack essay called “Why Smart Agents Don’t Learn,” with labels like: *face-saving summary*, *metric-protective synthesis*, *unilateral control by rubric*, *critique that preserves the premise*. This turns “the fleet should question rules” into observable critique behavior.

2. **Add “Deutero-learning / learning to learn,” anchored on Gregory Bateson, “The Logical Categories of Learning and Communication”**
   - **What to add:** Double-loop learning questions governing variables, but Bateson gives Sean a sharper ladder: Learning 0, I, II, III. The missing facet is that the fleet may need to learn **what kind of learning situation it is in**, not merely update a policy.
   - **Exemplar:** Gregory Bateson, **“The Logical Categories of Learning and Communication”** in *Steps to an Ecology of Mind*.
   - **Unlocks:** A **meta-agent protocol** that classifies every bad output before fixing it: “Is this retrieval failure, rubric failure, category error, taste failure, or identity drift?” Sean could produce an executable **Learning-Level Classifier** for the nightly critic, where not every failure becomes “improve prompt”; some become “wrong game being played.”

3. **Add “Viable System recursion,” anchored on Stafford Beer, *The Brain of the Firm***
   - **What to add:** The concept currently frames double-loop learning as an internal quality problem. Beer would reframe it as a governance architecture problem: does the fleet have a recursive system that can monitor operations, coordinate conflicts, audit policy, and adapt to the environment?
   - **Exemplar:** Stafford Beer, **The Brain of the Firm**; secondarily **Designing Freedom**.
   - **Unlocks:** A **fleet governance map** instead of another concept note. Sean could ship a portfolio one-pager or runbook mapping Vault Indexer/Synthesizer/Critic/Daily Driver/Meta-Agent into VSM functions: System 1 operations, System 2 coordination, System 3 control, System 4 intelligence, System 5 identity. The decision it unlocks: which missing agent is actually needed, instead of “make the critic smarter.”
