## What this is

Critiques from two external reasoners (gpt-5.5 via Codex CLI, Gemini 3 via Anti-Gravity CLI) of [[competitive-analysis]]. The synthesizer describes what the concept is; this expansion proposes what's missing.

## From Codex (gpt-5.5)

1. **Add “Strategic Inflection Point Analysis”**
   - **What to add:** A competitor-change mode that asks: *what external shift invalidates the current game board?* Competitive analysis should not only map rivals; it should identify when the basis of competition is changing.
   - **Anchor:** Andy Grove, *Only the Paranoid Survive*.
   - **Unlock for Sean:** This turns the concept from PM 101 into a **career-positioning artifact**: “Why agentic-engineering IC work is a strategic inflection point for PMs.” It would let Sean frame his transition as timing insight, not personal reinvention. Current failure mode: “I studied the market.” Better mode: “I saw the basis of advantage move from roadmap ownership to agent-system authorship.”

2. **Add “Value Chain / Activity System Mapping”**
   - **What to add:** A technique for analyzing competitors by the activities they perform differently, not by surface features or positioning claims. Ask: *which operating activities reinforce each other, and which tradeoffs make imitation hard?*
   - **Anchor:** Michael Porter, “What Is Strategy?” in *Harvard Business Review*.
   - **Unlock for Sean:** This unlocks a **portfolio one-pager** or **case-study teardown** of Code-Brain as an activity system: vault, hooks, skills, scheduled agents, local models, TTS, critic loop, job-hunt artifacts. Instead of listing tools, Sean can show why the pieces compound. Current failure mode: “I built many connected things.” Better mode: “I built a mutually reinforcing operating system competitors cannot copy by cloning one repo.”

3. **Add “Jobs-to-Be-Done Competitive Set”**
   - **What to add:** A competitor definition that includes anything hired to solve the same job, including spreadsheets, consultants, inbox rituals, Notion dashboards, recruiting agencies, or doing nothing. Competitive analysis should ask: *what is the user really hiring this for?*
   - **Anchor:** Clayton Christensen, Taddy Hall, Karen Dillon, and David Duncan, *Competing Against Luck*.
   - **Unlock for Sean:** This unlocks **agent spec writing** for intent-engineering and job-hunt demos. For example: “Code-Brain is not competing with Obsidian; it is competing with forgetting, stalled synthesis, generic career advice, and unconverted research.” Current failure mode: generic market map. Better mode: an executable demo where each agent is tied to a specific job, struggling moment, and replacement behavior.
