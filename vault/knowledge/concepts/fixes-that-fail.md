## Definition

A system archetype where a quick, symptomatic solution is applied to a problem, but the solution creates unintended consequences that worsen the original issue over time. In AI systems, this often involves using prompt engineering or synthetic data to boost immediate metrics, which subsequently degrades model authenticity and long-term performance. The mechanism traps the user in a cycle of increasing dependency on superficial fixes while the root cause accelerates.

## Context

Sean's curriculum explicitly identifies 'Fixes that Fail' as a key archetype. Applying this to his own workflow reveals that relying on high-throughput synthesis (the fix) may be masking deeper issues in knowledge retention or creative authority (the worsening problem).

## Evidence

> A quick fix addresses a symptom but creates unintended consequences that worsen the problem over time.

> Multiple parties exploit a shared resource (the digital data commons) until it is exhausted or poisoned (model collapse via synthetic data).

## Examples

- Relying on prompt engineering instead of structured UIs to solve user confusion.
- Using synthetic data to fill training gaps, leading to model collapse.
