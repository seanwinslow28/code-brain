## Definition

The architectural discipline of defining the invariant interface between human intent and autonomous agent execution, where the primary constraint is not API availability but file-system consistency. This mechanism treats the vault as a shared memory space where agents write artifacts that serve as implicit contracts for subsequent agents, enforcing state through persistence rather than real-time signaling. The design prioritizes 'hyper-intentionality' in visual and textual outputs to reduce cognitive load during review, ensuring that the agent's work is immediately legible to the human operator without requiring intermediate decoding steps.

## Context

Sean is building a personal knowledge vault where multiple agents (synthesizer, fleet memory, etc.) must coordinate without direct API calls. Understanding this file-system-based coordination pattern is critical for designing future portfolio projects that demonstrate mastery of agentic workflows beyond simple chat interfaces.

## Evidence

> the right interface for an autonomous agent is rarely an API; it's a file the agent and the next agent both read.

> The look is the portfolio's: an animator's pencil test, mounted in a frame. Every Substack hero is the same hand.

## Examples

- Using a 'master prompt recipe' with constant verbatim strings to ensure consistency across generations
- Defining style anchors as specific visual constraints (e.g., 'warm cream paper', 'no text') to guide AI output
