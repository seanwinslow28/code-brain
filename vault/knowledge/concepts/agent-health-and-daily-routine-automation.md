## Definition

This concept defines a latent failure mode where an agent's operational status is decoupled from its data freshness, creating a dependency chain that propagates stale context to downstream consumers. The mechanism relies on the assumption that process uptime equals output validity, which fails when the synthesizer produces empty or outdated results without raising an error flag. This creates a hidden vulnerability in the daily planning loop because the consumer cannot distinguish between a healthy agent and one that has silently failed to update its knowledge base.

## Context

Sean's morning planning relies on the integrity of his daily notes, which are generated by automated agents. If these agents report 'healthy' while delivering stale data, Sean makes decisions based on outdated information without realizing the automation layer has broken. This distinction is critical because standard health checks only monitor process execution, not the semantic quality or recency of the output.

## Evidence

> The tension lies between the superficial metric of agent uptime and the substantive requirement of data freshness.

> An agent can be 'healthy' in terms of process execution while failing to deliver the necessary context for downstream tasks.

## Examples

- A synthesizer fails silently overnight, causing the morning brief to inherit stale context that is not immediately visible in the agent's status logs.
