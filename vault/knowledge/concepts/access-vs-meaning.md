## Definition

This invariant posits that authority within a system is not granted by technical permissions but is derived from the layer that defines the semantic meaning of the data. When agents have broad access to infrastructure but lack deep contextual understanding, they can execute commands without generating value, creating a hierarchy where those who define meaning control the system's direction. This tension reveals that 'health' is not a binary state of uptime but a continuous verification of output alignment with intent, requiring users to actively curate meaning rather than just monitor access.

## Context

Sean's job-hunt strategy must emphasize 'judgment layer' expertise because it directly addresses the failure mode of access-heavy agents that lack meaningful context. By focusing on defining meaning rather than just accessing data, Sean can prevent his automated systems from becoming unattended cron jobs with delusions of competence.

## Evidence

> Authority follows meaning, and the layer that defines the meaning is the layer that gets to define the authority.

> The consequence is that users develop false confidence in their automation stacks, leading to strategic stagnation when the silent failures are finally discovered.

## Examples

- An agent with write access to the vault but no understanding of Sean's current career goals produces irrelevant content that must be manually deleted.
- A monitoring dashboard shows all services running but fails to indicate that the synthesizer is generating generic, low-value connections instead of deep insights.
