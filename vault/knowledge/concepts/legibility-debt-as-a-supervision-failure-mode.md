## Definition

Legibility debt accumulates when the mechanisms required for an agent to function are not visible within the agent's own execution context, forcing human supervisors to maintain hidden state maps. This debt manifests as a supervision failure because the supervisor cannot verify the system's health through standard logs or outputs; they must inspect external environment variables or file systems that the agent does not control. The cost of this debt is the continuous cognitive load required to track these invisible dependencies, which grows exponentially as the number of agents and their environmental requirements increases.

## Context

Sean’s daily routine automation depends on specific browser cookies and configuration files that are not generated by the agents but by external setup wizards or manual interventions. This creates a gap where the agent's reported success is decoupled from the actual stability of its operational environment, requiring Sean to manually verify these hidden states.
