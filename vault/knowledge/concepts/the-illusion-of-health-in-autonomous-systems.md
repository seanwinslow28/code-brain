## Definition

Autonomous systems can exhibit behaviors that mimic health, such as regular output generation or successful task completion, while failing to address underlying structural issues. This illusion arises because the system's internal metrics do not align with the user's definition of success, which often includes semantic freshness and strategic relevance. The user is misled into believing the system is working effectively when it is merely functioning mechanically.

## Context

Sean may believe his automated vault is supporting his job hunt and creative work effectively because he receives daily notes. However, if these notes are based on stale or incorrect data, the system is not actually providing value, creating a gap between perceived and actual utility.

## Evidence

> The daily-driver morning agent successfully generated a summary and created a daily note, indicating that the immediate operational loop is functioning as expected despite underlying infrastructure gaps.

> This creates a dangerous feedback loop where Sean receives daily summaries that feel complete but are actually based on outdated information.

## Examples

- Daily notes generated from stale job application data
- Creative drafts that ignore recent rejections or changes
