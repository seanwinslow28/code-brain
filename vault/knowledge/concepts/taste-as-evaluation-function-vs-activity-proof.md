## Definition

This mechanism distinguishes between two modes of creative labor: generating artifacts versus evaluating them against a personal aesthetic standard. When 'activity proof' (e.g., run counts, token usage) becomes the primary metric, it substitutes for genuine insight, leading to a systemic trust deficit where consistency is confused with correctness. True taste requires decoupling the judge from the candidate pool to ensure evaluation reflects external truth rather than internal consistency.
