## Definition

Intent engineering shifts from objective repetition to constraint preservation under changing feedback loops. This control-theoretic model identifies hazards by analyzing unsafe interactions even when every component operates as designed. It tests four specific failure modes: action omitted, action issued, wrong timing/order, or action continued/stopped incorrectly.

## Context

Sean's agent fleet manages critical career artifacts like resumes and daily notes. A standard 'intent' definition fails to catch subtle coordination failures where agents act correctly in isolation but produce hazardous outcomes together. This analysis provides a safety case artifact for his professional portfolio.

## Evidence

> Intent is not the objective an agent repeats; it is the constraint its actions must preserve under changing feedback.

> Accidents can arise from unsafe interactions even when every component operates as designed.
