## Definition

A strategic entry point defined by the specific moment a user abandons their current habit because the combined force of situational push and solution pull exceeds the anxiety of switching. This wedge is not merely a feature but a temporal window where high-visibility friction can be exploited before competitors standardize the underlying component into a commodity. The mechanism relies on identifying nodes that are currently painful enough to drive action but visible enough to capture attention, creating a defensible moat only if the productization speed outpaces market commoditization.

## Context

Sean must identify high-visibility nodes to defend while treating hidden components as table stakes, forcing a strategic choice between productizing novelty or open-sourcing infrastructure. Without this precise wedge identification, any new venture risks building undifferentiated work that fails to capture initial demand.
