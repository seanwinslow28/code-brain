## Definition

This tension defines the conflict between maintaining high availability of agent processes and ensuring those processes generate meaningful cognitive output for the user. It highlights that uptime is a necessary but insufficient condition for value; an agent can be perpetually online while contributing nothing to decision-making. The core challenge is aligning operational metrics with strategic outcomes rather than optimizing for execution counts alone.

## Context
