## Definition

This pattern describes the structural shift where a creator's primary role transitions from artistic execution to infrastructure maintenance due to the complexity of integrating specialized tools. As Sean adds more capabilities to his pipeline, the marginal utility of each new tool decreases while the cognitive load of managing their interactions increases. This forces him to spend more time debugging the system than creating content, effectively turning him into an infrastructure engineer rather than a creator.

## Context

Sean is attempting to build a portfolio project that demonstrates technical proficiency in agentic animation. However, the current tooling stack creates a barrier where he must act as a systems integrator before he can produce any creative output, undermining the efficiency gains he seeks in his job-hunt portfolio.

## Evidence

> The marketed pitch is that animators describe an animation and Claude produces it, but in practice users must think in React/SVG/timing terms, iterate on intricate prompts, and repeatedly correct both code and creative output before anything is production-ready.

> Connecting Claude Code to external animation services, renderers, and desktop tools requires complex setup, and stacking MCP servers, hooks, and skills makes workflows feel slow and bloated before any visual output is reached.

## Examples

- Users must think in React/SVG/timing terms instead of describing animations naturally.
- Stacking MCP servers on top of hooks on top of skills makes workflows feel slow and bloated.
