## Definition

This pattern describes the structural shift where a creator's primary role transitions from artistic execution to infrastructure maintenance due to the complexity of integrating specialized tools. As Sean stacks MCP servers, hooks, and skills to achieve agentic animation, the cognitive load of managing these interactions increases disproportionately to the creative output generated. The tooling itself becomes the bottleneck, forcing the user to debug code and correct AI outputs rather than focusing on aesthetic decisions or narrative structure.

## Context

Sean is attempting to build a portfolio project using agentic animation pipelines. This divide threatens his ability to demonstrate creative competence because he spends more time acting as an infrastructure engineer debugging the pipeline than creating content that showcases his artistic vision.

## Evidence

> Connecting Claude Code to external animation services, renderers, and desktop tools requires complex setup, and stacking MCP servers, hooks, and skills makes workflows feel slow and bloated before any visual output is reached.

> The marketed pitch is that animators describe an animation and Claude produces it, but in practice users must think in React/SVG/timing terms, iterate on intricate prompts, and repeatedly correct both code and creative output before anything is production-ready.

## Examples

- Stacking MCP servers on top of hooks on top of skills results in workflows that feel slow and bloated.
- Users must think in React/SVG/timing terms rather than describing animations naturally.
