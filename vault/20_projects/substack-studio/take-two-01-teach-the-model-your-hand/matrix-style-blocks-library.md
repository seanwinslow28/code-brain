# Morph Matrix Run Kit: 12 style blocks

One file to run the whole matrix. The two fixed blocks below never change. Swap only the numbered STYLE block. Re-anchor every new style to the headshot, never to a stylized output. Save every generation (including rerolls) as `NN-style-path.png` with one line on what you changed.

## How to use (the controlled experiment)

1. Open one ChatGPT thread. Upload the headshot.
2. Paste FIXED BLOCK 1 + the STYLE block you are testing + FIXED BLOCK 3 + the RENDER line. In that order.
3. **Register is held constant** across all 12 (a moderate, recognizable caricature, dial Step 1) so the only variable is the medium. That is what makes this a fair test of "what good looks like" per style. Run the caricature dial as a separate axis on your 2 to 3 finalists afterward.
4. Score each result 0 to 2 on the rubric at the bottom.
5. The path note on each block is the recommended starting path; where it says "run both," do edit and generate so the matrix shows which one wins for that look.

## FIXED BLOCK 1 — LIKENESS-LOCK (paste every time, never change)

```
SUBJECT: a portrait of the same adult man in the reference photo. Keep him
unmistakably recognizable as the same person. Preserve, in this priority:

- Eyebrows: strong, fairly straight horizontal brows with a heavier line weight.
- Eyes: blue, set about one eye-width apart at the inner corners; keep that spacing.
- Proportions: keep the relative spacing between eyes, nose, and mouth unchanged.
- Jaw and face outline: angular jaw, squared chin (about a 100 to 110 degree corner
  at the jaw); do not round the face.
- Hair: dirty-blonde / warm light-brown, medium-short and tousled, with a small
  upward cowlick at the crown; not platinum, not flat, not a clean helmet.
- Skin: fair and warm, with light stubble across the jaw and upper lip.
- Build: a grown man, athletic.
- Expression: an easy, closed-mouth smile.
```

## FIXED BLOCK 3 — CONSTRAINTS (paste every time, never change)

```
CONSTRAINTS:
- Change only what the STYLE block names. Keep the face geometry, hair, and the
  features listed in SUBJECT exactly as in the reference. Re-read SUBJECT before drawing.
- Render fully in the named medium. Do not retain photographic shading, lighting,
  or texture from the reference; redraw it in the medium.
- No text, words, letters, numbers, captions, labels, logos, watermarks, or
  signatures anywhere. Purely pictorial.
- Composition: a head-and-shoulders bust, facing the viewer, centered.
```

## RENDER line (paste last)

```
RENDER: a head-and-shoulders bust portrait, facing the viewer. Change only the
medium and style; keep everything in SUBJECT and CONSTRAINTS the same.
```

## The 12 STYLE blocks (swap one at a time)

### 01 — Pencil-test (house control)  ·  save: `01-pencil-test`
```
STYLE:
- Medium / substrate: graphite-and-ink drawing on warm cream paper with visible grain.
- Mark-making: confident graphite linework, fine cross-hatching for shadow, faint
  light-blue construction underdrawing left visible.
- Palette rule: monochrome graphite throughout, plus exactly ONE warm amber accent.
- Register: a clear, moderately exaggerated caricature, plainly recognizable as him.
- Signature move: one soft amber watercolor bloom behind the head, sitting behind the
  linework, bleeding into the paper, never on top, never splatter.
```
Path: hybrid (edit, then force the medium hard). Watch: photographic shading leaking through; keep it graphite.

### 02 — Charcoal life-study  ·  save: `02-charcoal`
```
STYLE:
- Medium / substrate: vine and compressed charcoal on toned gray newsprint.
- Mark-making: loose gestural strokes, smudged tonal masses, sharp eraser highlights;
  build the face from shadow shapes rather than outline.
- Palette rule: monochrome charcoal, no color at all.
- Register: a clear, moderately exaggerated caricature, plainly recognizable as him.
- Signature move: visible finger-smudge and the rough torn edge of the newsprint.
```
Path: edit. Watch: tonal mush erasing the eye-spacing and jaw; keep the brow crisp.

### 03 — Ballpoint biro  ·  save: `03-biro`
```
STYLE:
- Medium / substrate: a ballpoint-pen drawing on lined off-white notebook paper.
- Mark-making: obsessive layered hatching in one pen color, tone built by line density,
  a few loose doodles drifting into the margin.
- Palette rule: a single blue-black ballpoint ink on cream paper.
- Register: a clear, moderately exaggerated caricature, plainly recognizable as him.
- Signature move: the faint waxy ballpoint sheen and over-worked cross-hatch in the shadows.
```
Path: generate, or hybrid. Watch: over-darkening swallowing the features; keep highlights open.

### 04 — Woodblock relief print  ·  save: `04-woodblock`
```
STYLE:
- Medium / substrate: a black relief print pulled from a hand-carved woodblock onto cream stock.
- Mark-making: bold reductive carved cuts, chunky positive shapes, white gouges where the
  blade lifted, visible wood grain in the ink.
- Palette rule: black ink on cream, plus one optional spot color.
- Register: a clear, moderately exaggerated caricature, plainly recognizable as him.
- Signature move: the chiseled hand-carved edge and uneven hand-pulled inking.
```
Path: generate (flat carved shapes fight a photo). Watch: likeness collapsing to a generic carved face; lean on the brow, jaw, and cowlick.

### 05 — Risograph two-color  ·  save: `05-riso`
```
STYLE:
- Medium / substrate: a risograph print on off-white stock.
- Mark-making: grainy halftone dot shading, slight ink misregistration, visible paper tooth.
- Palette rule: exactly two inks (one warm, one ink-dark), overlapping into a third tone
  where they cross.
- Register: a clear, moderately exaggerated caricature, plainly recognizable as him.
- Signature move: the off-register edge where the two ink layers do not quite line up.
```
Path: edit or hybrid. Watch: the halftone flattening the face; keep feature spacing legible.

### 06 — Mid-century flat / paper-cut  ·  save: `06-midcentury-flat`
```
STYLE:
- Medium / substrate: flat printed shapes, the look of cut-and-layered colored paper.
- Mark-making: clean hard-edged shapes, minimal interior detail, subtle paper texture
  inside each shape; build features from shape, not line.
- Palette rule: a strict limited palette of three or four muted, slightly retro colors.
- Register: a clear, moderately exaggerated caricature, plainly recognizable as him.
- Signature move: bold negative space and one shape overlapping another for depth.
```
Path: generate. Watch: abstraction erasing the specific brow/jaw; keep those as deliberate shapes.

### 07 — Gouache illustration  ·  save: `07-gouache`
```
STYLE:
- Medium / substrate: opaque gouache on warm paper.
- Mark-making: flat matte color fields with visible directional brushwork and soft edges,
  gentle paper texture showing through.
- Palette rule: a warm, slightly muted illustrative palette, limited and harmonious.
- Register: a clear, moderately exaggerated caricature, plainly recognizable as him.
- Signature move: the chalky matte gouache surface and a few visible brush ridges.
```
Path: edit. Watch: usually holds well; check the hair shape and cowlick survive.

### 08 — Watercolor wet-on-wet  ·  save: `08-watercolor`
```
STYLE:
- Medium / substrate: watercolor on cold-press paper.
- Mark-making: soft bleeding washes, blooms where pigment pools, a few confident ink
  contour lines laid on top.
- Palette rule: a light, translucent palette with lots of white paper left breathing.
- Register: a clear, moderately exaggerated caricature, plainly recognizable as him.
- Signature move: the wet bloom and granulation where colors run into each other.
```
Path: edit. Watch: features dissolving in the wash; let the ink contour hold the identity.

### 09 — Stained glass  ·  save: `09-stained-glass`
```
STYLE:
- Medium / substrate: a leaded stained-glass panel.
- Mark-making: bold black lead lines enclosing flat color cells; features simplified
  into glass segments.
- Palette rule: rich jewel tones in discrete segments, no blending across cells.
- Register: a clear, moderately exaggerated caricature, plainly recognizable as him.
- Signature move: light glowing through the colored glass, with heavy came lines.
```
Path: generate. Watch: segmentation flattening identity; place lead lines to follow his real planes.

### 10 — Tintype / wet-plate photo  ·  save: `10-tintype`
```
STYLE:
- Medium / substrate: an antique wet-plate tintype photograph.
- Mark-making: a silvery tonal range, soft focus falloff, chemical streaks and plate
  scratches, vignetted edges.
- Palette rule: monochrome silver, aged, cool shifting to warm.
- Register: a clear, moderately exaggerated caricature, plainly recognizable as him.
- Signature move: period gravity, scratches, and uneven emulsion at the plate edges.
```
Path: edit. Watch: likeness is easy here, so the real test is the "hand / ownable" axis (is it a deliberate look or just a filter?).

### 11 — 16-bit pixel sprite  ·  save: `11-pixel`
```
STYLE:
- Medium / substrate: pixel art on a visible grid.
- Mark-making: hard pixel edges, ordered dithering for shading, no anti-aliasing.
- Palette rule: a tight indexed palette of roughly 12 to 16 colors.
- Register: a clear, moderately exaggerated caricature, plainly recognizable as him.
- Signature move: a readable silhouette at small size and chunky dithered shadows.
```
Path: generate. Watch: whether the hair tell and silhouette survive the low resolution. (Ties to 16BitFit.)

### 12 — Topographic contour-map portrait (wild card)  ·  save: `12-topo`
```
STYLE:
- Medium / substrate: a printed topographic survey map.
- Mark-making: build the entire face from stacked elevation contour lines that follow its
  planes; thin uniform line weight; a few sparse grid ticks.
- Palette rule: a single map-ink color on pale paper, plus one optional elevation tint.
- Register: a clear, recognizable likeness rendered purely in contour lines.
- Signature move: contour rings packed tight where the face is steep (nose, brow, jaw)
  and spaced wide on the flat planes.
```
Path: generate, or hybrid. Watch: the hardest likeness test (highest uniqueness). If identity survives full abstraction, this is your most ownable look.
