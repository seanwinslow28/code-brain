# Cap-policy governance

`cap_policy.json` is the one content home for cap numbers. Editing any cap value is a cap change and requires Sean's explicit approval — the plan → approve → execute gate recorded in **the-oracle's** CLAUDE.md (rule 2 / §Spend governance) and the approved F8b plan (`the-oracle/docs/phase-plans/2026-07-18-f8b-ledger-governance.md`). Content review and activation are separate gates: reviewed content lives in git, while `python -m council.policy activate` publishes the exact validated snapshot to the shared spend root as `council-policy-active.json`. The shared activation, not any process's local checkout, is the cross-process authority.

Until the remaining F8b migrations complete, the-oracle's legacy value home (`the-oracle/oracle/config.py`) still exists; Tasks 5–6 wire it through the registry's enforced equality check so any drift between a code home and the activated policy fails closed instead of silently diverging. The council CLI, discovery CLI, and panel-vs-single experiment now load their tool and aggregate caps from this registry. Money values are authored as JSON decimals (`7.00`, never `7`) so one semantic policy has exactly one canonical hash.

Policy version 3 completes Sean's 2026-07-18 Task 3c approval across the council and discovery migrations. The council enumeration remains `[5.50, 11.50, 13.00]` with $45/day and $250/month. Discovery is `[3.25, 4.50, 7.50, 30.00]` with $30/day and $100/month; the first three values cover quick/standard/deep and the fourth is the panel-vs-single experiment's documented per-query/daily-cap semantic. The approval landed in two commits, but distinct policy content must never share one version, so the discovery half advances v2 to v3.

Council uses `reservation_basis: "worst_case"`. Discovery intentionally stays labeled `"estimate"`: its reservation includes the priced client-bounded legs plus Sean's declared allowance for client-unboundable server-side spend.

`sum_exceeds_aggregate: true` asserts the decided relation: tool daily caps sum to $320 > $245 and monthly caps sum to $1,350 > $1,000. The shared aggregate can therefore bind first and starve a tool before its own cap; admission must refuse loudly and deterministically.
