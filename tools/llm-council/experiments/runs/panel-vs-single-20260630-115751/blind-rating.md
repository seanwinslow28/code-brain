# Blind pain-point rating

Topic: artists, writers, and designers who say AI is a slot machine — the same prompt never gives the same result twice — and who have stopped chasing prompts in favor of building a repeatable system they can trust

## Set 1

1. **Non-determinism: the same prompt never reproduces the same result** — Creators report that generative AI behaves like a slot machine—identical prompts yield random, inconsistent outputs—making it impossible to build a repeatable professional workflow they can trust. This has driven them to abandon prompt chasing in favor of stable, controllable systems.
   - quote: "They say the same prompt never gives the same result twice, which makes it impossible to build a repeatable, professional workflow they can trust, so they have stopped "prompt chasing" and are asking for more stable, controllable systems."
   - quote: "A recurring complaint is that generative AI behaves like a casino: you pull the lever (enter a prompt), and you get a random output, often inconsistent with what worked yesterday."
   - quote: ""You feed it a prompt and pull the lever… It's a slot machine built from other people's labor.""

   - source: https://time.com/article/2026/03/26/ai-slop-is-threatening-musicians-can-tech-companies-stem-the-tide-/
   - source: https://thebulletin.org/2022/10/ai-is-plundering-the-imagination-and-replacing-it-with-a-slot-machine/
2. **Model updates break carefully built workflows ('what worked last month no longer works')** — Providers update models and datasets without notice, so prompts that previously worked suddenly produce different or worse results. The constant churn destroys stable production pipelines and means users can't depend on any stable mapping from prompt to output.
   - quote: "Working artists report that when AI providers update their models, prompts that used to work suddenly produce different or worse results, breaking carefully built workflows."
   - quote: "respondents also note that AI tools are unreliable and constantly changing, making it impossible to build stable production pipelines."
   - quote: "users cannot depend on any stable mapping from prompt to output because models and datasets are repeatedly updated without notice."
   - source: https://www.newyorker.com/culture/infinite-scroll/is-ai-art-stealing-from-artists
   - source: https://www.theguardian.com/technology/2024/apr/02/musicians-demand-protection-against-ai

3. **Missing controls for reproducibility (seeds, version locks, version pinning)** — Creators have a concrete unmet need for deterministic behavior or explicit controls—seeds, settings, and the ability to pin a project to a specific model version—so prompts don't drift in meaning and past results can be reliably reproduced. They feel tools instead prioritize novelty and engagement over reproducibility.
   - quote: "Creators want deterministic behavior (the same input producing the same output when desired), or at least clear controls (seeds, version locks, settings) that reliably reproduce past results."
   - quote: "Version pinning: the ability to lock a project to a specific model version so prompts don't change meaning over time."
   - quote: "They complain that existing tools prioritize novelty and engagement over reproducibility."
   - source: https://www.wired.com/story/ai-bots-streaming-music/

4. **Practice degraded into 'trial-and-error gambling' instead of craft** — The volatility and unpredictability are framed not just as inconvenience but as an erosion of artistic craft—turning skilled creative practice into casino-style gambling, with the slot-machine metaphor extending to addiction/compulsion dynamics.
   - quote: "Creators complain that this volatility "turns artistic practice into trial-and-error gambling instead of craft.""
   - quote: "Many artists, writers, and designers who describe generative AI as a "slot machine" are frustrated by its unpredictability, lack of control, and constant model changes."
   - quote: "I wish I could ask my 600,000+ readers how they deal with both: overload & addiction."

## Rating criteria

Rate each set on:
1. **Signal density** — fraction of points naming a specific, real, recent user frustration (not generic).
2. **Evidence grounding** — quotes/URLs that concretely support each point.
3. **Distinctness / dup-rate** — are the points non-overlapping, or near-duplicates padding the count?
4. **Actionability** — could a PM or creator act on this as an opportunity?

Pick a winner per criterion, then an overall winner with a one-paragraph rationale. You are blind to how each set was produced — judge only the content.
